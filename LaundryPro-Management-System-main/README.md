#  LaundryPro Management System

A modern and responsive Laundry Management System built with **HTML**, **CSS**, and **JavaScript**. LaundryPro helps laundry businesses efficiently manage customers, orders, payments, and users through an intuitive dashboard.



##  Overview

LaundryPro is a web-based management system designed to simplify daily laundry operations. It enables administrators and employees to organize customer records, process laundry orders, track payments, and manage users in one place.

The project was built to practice real-world JavaScript concepts including CRUD operations, authentication, authorization, local storage, and responsive dashboard design.



##  Features

-  User Authentication (Login & Register)
-  Role-Based Authorization (Admin & Employee)
-  Interactive Dashboard
-  Customer Management
-  Order Management
-  Payment Management
-  User Management
-  Search Functionality
-  Responsive Design
-  Local Storage Data Persistence

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Font Awesome
- Google Fonts
- Git
- GitHub



##  System Roles

###  Administrator

- Manage all customers
- Manage all orders
- Manage all payments
- Manage all users
- View all dashboard statistics

###  Employee

- Manage their own customers
- Create and update their own orders
- Record payments
- View their own dashboard statistics
